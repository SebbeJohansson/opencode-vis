# AGENTS.md

Context for AI agents working in this repository.

## Maintaining this file

This file is a living document. If you learn something while working here that a
future agent would need to know — a convention, a gotcha, a command, an
architectural constraint — add it. Keep entries short and factual, and delete
anything that has become wrong.

Rules for edits:

- One fact per entry, phrased so it is actionable without extra context.
- Only add things that are not already obvious from the code, the README, or git history.
- Do not add task-specific notes or changelog entries; this is not a log.
